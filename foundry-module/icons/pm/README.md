# Иконки статусов

Взяты целиком, с исходной сортировкой по папкам, из сеттинга
[Leetram519/Project-Moon-TTRPG](https://github.com/Leetram519/Project-Moon-TTRPG) (`src/assets/icons/Statuses` и
`src/assets/icons/limbus_assets`, коммит `fd3965f`). Сами изображения — из игр Project Moon (Limbus Company и др.),
фанатское использование, как и в сеттинге.

- `Statuses/` — основные статусы.
- `limbus/` — все эффекты Limbus Company: `Basic Effects/<вид>` (Burn, Bleed, Tremor со всеми разновидностями, Sinking,
  Power Up/Down, DMG Up/Down, Fragility, Protection…), фракции, Mirror Dungeon, Walpurgis, Canto и т. д.

Какая иконка у какого статуса модуля — `site/pm-statuses.js` (поле `icon`). В Foundry любую из них можно выбрать
вручную: `modules/pm5e/icons/pm/…`.
