# Assets_Lobotomy — спрайты оформления «Lobotomy Corporation»

Спрайты интерфейса Lobotomy Corporation для оформления `lobotomy` (см. README сайта, раздел «Оформления»). Отобраны из
выгрузки игры (`Assets/Timed_Assets/Lobotomy_Corp`, коммит `531e883`): только интерфейс и фоны отделов — без персонажей,
аномалий, логотипов отрядов и букв-спрайтов. Набор скудный (нет шрифтов, значков работ и эмблем отделов), поэтому часть
деталей — обычный CSS: штриховка «осторожно» цвета отдела, сетка фона, кремовые подписи.

Все файлы — в деле (`index-lobotomy.html`, `site/themes/lobotomy/*.css`). Новый спрайт кладите в подходящую папку с понятным
именем и допишите строку сюда. Исходная выгрузка удалена из репозитория; вернуть её для подбора новых спрайтов:
`git checkout 531e883 -- Assets/Timed_Assets/Lobotomy_Corp` (и не коммитьте обратно).

«Собрано» — файл не из игры как есть, а сделан из её спрайтов (как — в колонке «Что это»).
