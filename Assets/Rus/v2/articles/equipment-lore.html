Значение уровня редкости (Tier Value)

Для обозначения качества аугментаций, тканей и предметов Сингулярности используется числовое значение Tier Value:

  • Common (Обычный): Tier Value = 1
  • Uncommon (Необычный): Tier Value = 2
  • Rare (Редкий): Tier Value = 4
  • Very Rare (Очень редкий): Tier Value = 5
  • Legendary (Легендарный): Tier Value = 7

Аугментации и протезы: в чём разница?

Согласно Поправке об этике ИИ, контролируемой Главой, протезы не могут выглядеть как человеческие части тела — они всегда явно механические. Биотические аугментации позволяют сохранить человеческий облик и родные органы, но уничтоженный протез легко заменить на идентичный, тогда как родную руку вернуть нельзя.

Одежда портных (Attire)

Одежда из специализированной ткани даёт базовый КД 12 + модификатор Ловкости (макс. +3) в дополнение к свойствам ткани. Поскольку это одежда, а не броня, владение бронёй для неё не требуется.
