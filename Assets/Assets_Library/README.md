# Assets_Library — спрайты оформления «Library of Ruina»

Спрайты интерфейса Library of Ruina для оформления `library` (см. README сайта, раздел «Оформления»). Отобраны из
выгрузки игры (`Assets/Libruary_Timed_Assets`, коммит `8288889`): только интерфейс — рамки страниц, кнопки, орнаменты,
значки и эмблемы; без персонажей (библиотекари, гости), аномалий, именных табличек сефир и надписей. В выгрузке нет фонов
этажей, поэтому фон зала — обычный CSS (тёплый свет, виньетка, едва заметные полки — `site/themes/library/base.css`),
а магический круг — только на главной.

Почти весь интерфейс игры в выгрузке белый (в игре его подкрашивает движок), поэтому большинство файлов здесь —
«собрано»: перекрашено в золото, а рамки, где оригинал несимметричен, сшиты заново из его угла. Как именно — в колонке
«Что это». Цвета: линия рамок `#DEBA7C`, яркая (наведение) `#FFDDA0`, значки `#ECCC92`, поле окон `#110C08`.

Все файлы — в деле (`index-library.html`, `site/themes/library/*.css`). Новый спрайт кладите в подходящую папку с понятным
именем и допишите строку сюда. Исходная выгрузка удалена из репозитория; вернуть её для подбора новых спрайтов:
`git checkout 8288889 -- Assets/Libruary_Timed_Assets` (и не коммитьте обратно).

## Рамки — `frames/`

Растягиваются через `border-image` (9-slice): «срез N» — число после `url()`. Толщина рамки у элемента — 1 px, спрайт
рисуется шире (`border-image-width`), поэтому уголки ложатся на поле и не сдвигают текст.
