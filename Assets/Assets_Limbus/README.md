# Assets_Limbus — спрайты оформления «Limbus Company»

Спрайты интерфейса Limbus Company для оформления `limbus` (см. README сайта, раздел «Оформления»). Отобраны из выгрузки игры:
только интерфейс — без героев Limbus (Данте, грешники), портретов и иконок грехов.

«В деле» — файл уже используется (`index-limbus.html`, `site/themes/limbus/*.css`), «запас» — подобран для следующих страниц.
Новый спрайт кладите в подходящую папку с понятным именем и допишите строку сюда.
