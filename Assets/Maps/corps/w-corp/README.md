# WARP (W) — набор Крыла

Район 23. Места на карте Города (world.json): Станция ВАРП.
Правила папки: всё отсюда генератор ставит только в Районе этого Крыла (`districts: ["Крыло W"]`);
вручную из библиотеки — где угодно. Общие требования — `../README.md`.

## Основа

- [ ] `walls/` — Стены — бесшовные 256×256: вид «лицевой стороны» (ложится на грань стены, верх картинки = верх стены). 1–2 шт.: наружная и внутренняя.
- [ ] `floors/` — Полы — бесшовные 256×256. 2–3 шт.: холл, рабочие помещения, служебные.
- [ ] `doors/` — Двери — ВИД СПЕРЕДИ (картинка вписывается в грань стены между перемычкой и полом): обычная 256×256 и парадная/шлюз 512×256. Ширина проёма = ширина картинки в клетках.
- [ ] `windows/` — Окна — ВИД СПЕРЕДИ: 256×256 (или 512×256 для широкого).
- [ ] `roofs/` — Кровля — бесшовная 256×256, 1 шт.
- [ ] `signs/` — Вывеска `sign.svg|png` 512×256 (генератор вешает её у входа в Районе Крыла), эмблема `emblem` 256×256, логотип на полу `floor-logo` 768×768.

## Фирменные вещи (`objects/`)

- [ ] Двойное сиденье вагона (512×256)
- [ ] Багажная полка
- [ ] Пол вагона (бесшовный)
- [ ] Тамбурная дверь (вид спереди) — кладётся в `doors/`
- [ ] Турникеты станции (256×128)
- [ ] Платформа: край с разметкой (лента)
- [ ] Табло расписания (масштабируемое)
