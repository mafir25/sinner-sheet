# Корпорация K — набор Крыла

Район 11. Места на карте Города (world.json): Кальв, Филиал L Corp K-02, Бар и Жаровня Ынбон, Лаборатория Донрана.
Правила папки: всё отсюда генератор ставит только в Районе этого Крыла (`districts: ["Крыло K"]`);
вручную из библиотеки — где угодно. Общие требования — `../README.md`.

## Основа

Сейчас лежат **временные** процедурные заготовки (палитра со скриншотов холла K Corp); на доработку — `PROMPTS.md`.

- [x] `walls/` — Стены — бесшовные 256×256: вид «лицевой стороны» (ложится на грань стены, верх картинки = верх стены). 1–2 шт.: наружная и внутренняя.
- [x] `floors/` — Полы — бесшовные 256×256. 2–3 шт.: холл, рабочие помещения, служебные.
- [x] `doors/` — Двери — ВИД СПЕРЕДИ (картинка вписывается в грань стены между перемычкой и полом): обычная 256×256 и парадная/шлюз 512×256. Ширина проёма = ширина картинки в клетках.
- [x] `windows/` — Окна — ВИД СПЕРЕДИ: 256×256 (или 512×256 для широкого).
- [x] `roofs/` — Кровля — бесшовная 256×256, 1 шт.
- [x] `signs/` — Вывеска `sign.svg|png` 512×256 (генератор вешает её у входа в Районе Крыла), эмблема `emblem` 256×256, логотип на полу `floor-logo` 768×768.
