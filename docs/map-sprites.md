# Спрайты редактора карт — что нарисовать

Список для художника: всё, что сейчас стоит заглушкой, что не хватает генерации и что нужно для
тематических заготовок (Lobotomy Corp, Библиотека, Варп-экспресс…). Отмечайте готовое: `[x]`.
Устройство наборов — `docs/map-editor.md` §4, правила размещения — §5.

## Общие требования
- **256 px на клетку.** Объект 2×1 клетки = картинка 512×256. Размеры ниже — уже в пикселях.
- PNG с прозрачным фоном (или SVG). Пиксель-арт — галочка «Пиксель-арт» в «✎ Разметить».
- **Вид строго сверху. Верх картинки — задняя сторона объекта** (спинка стула, задняя стенка шкафа,
  изголовье кровати): так объект встаёт к стене лицом в комнату.
- **Бесшовные:** полы, стены, кровля, местность (местность — непрозрачная, форму задаёт кисть).
  Ленты вдоль путей (`objects/linear/`) — бесшовные слева-направо.
- Файл → папка в `Assets/Maps/…` → `npm run gen:maps` → правила в «✎ Разметить»
  (**без правил генератор объект не ставит**). Замена с тем же именем файла — без перенастройки.
- Варианты одного объекта (ящик-1, ящик-2…) — одна папка + поле «Группа вариантов»: генерация меньше повторяется.

## В. Заготовки генерации (пре-генерации)
Тематические варианты для окна «✦ Генерация»: свой стиль (материалы), тип здания (какие комнаты)
и, где нужно, своя планировка. Пометка **«код»** — кроме спрайтов нужна новая планировка в генераторе
(`map-app/src/gen/`); без пометки хватает стиля и типа здания (`gen/kit.ts`). Спрайты — сверх разделов А и Б.
